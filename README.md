## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/chandan966/portfolio.git
```

Go to the project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run on the local development server provided by Vite.

## 📄 Resume

The portfolio includes a downloadable CV.

Place your resume inside:

```text
public/resume.pdf
```

The Navbar download button will then access:

```text
/resume.pdf
```

## 🖼️ Images

Portfolio images are stored inside:

```text
public/images/
```

Example:

```text
profile.jpg
cg-logo.png
university-logo.png
```

They can be used in React like:

```jsx
<img src="/images/profile.jpg" alt="Chandan Ghanghav" />
```
